导入主题

主 CSS 最多 1 MB（1,048,576 字节）。可补选本地字体、图片；不自动下载远程资源或加载 @import。

支持 WOFF/WOFF2/TTF/OTF 字体和 PNG/JPEG/WebP/GIF 图片。最多 64 个资源，单个最多 16 MB，合计最多 24 MB。目录中的其他 CSS 不会自动合并。背景图片默认关闭，可在下方开启。

统一样式配置

所有主题共用一套配置。保存后，在网页中再次点击“应用主题”生效；已打开的正文不会立即改变。

使用与兼容性

默认保留网站宽度、布局和代码配色，并保护公式、图表及交互控件。可通过统一配置逐项调整。编辑器界面、动画及 @import 会跳过；背景图片可能受到网页 CSP 限制，资源缺失或加载失败可在日志中查看。

打开博客 → 点击扩展 → 识别正文并确认 → 应用主题。识别失败时，可输入正文容器的 CSS 选择器。点击“恢复原样”即可撤销扩展样式。
