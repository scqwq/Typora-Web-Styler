02 · 配置

所有主题共用这套设置。勾选要保留的原文样式，保存后回到网页再次应用主题。

保留网页的熟悉感

默认保留网站宽度、布局和代码配色，保护公式、图表与交互控件。背景图片默认关闭，可在上方开启；页面 CSP 可能影响资源加载。编辑器界面、动画与 @import 暂不支持，处理详情可在日志中查看。

如果正文没有被正确识别，可以在扩展小窗口中填写正文容器的 CSS 选择器。“恢复原样”随时可以撤回扩展样式。

04 · 自动应用

这里只设置偏好。在网页小窗口中成功应用一次主题后，才会记住那个标签页及所选主题。

已登记的标签页刷新、切换章节时自动识别正文。其他标签页不受影响；分别手动应用后可各自登记。

勾选后只跟随最初登记的网站；不勾选则可跟随该标签页跨网站导航，需要额外的网站访问授权。

关闭标签页、重启浏览器或重新加载扩展后，临时登记会清除。“恢复原样”会暂停该标签页自动应用，再次手动应用后恢复。识别不明确的页面会跳过。

选一个喜欢的主题，安心读完下一篇。
