本地 CSS 与目录

最多 2 MB。

配套字体、图片与目录

字体 WOFF / WOFF2 / TTF / OTF，图片 PNG / JPEG / WebP / GIF。最多 64 个资源，单个 16 MB、合计 24 MB。目录内的 CSS 依赖自动合并，远程资源不加载。

本地 ZIP

最多 48 MB，解压后最多 96 MB。

从链接导入

支持 theme.typora.io 主题页、GitHub 仓库 / Release 和 HTTPS ZIP。整包可能含多个主题或配色，建议下载查看后本地导入。

获取时需授权下载来源，导入后可离线使用。

各配色分别导入，仅合并所选主题的包内依赖。字体、远程入口及空文件不可单独导入。

主题沿用设置

    
在扩展面板手动应用一次后，该标签页刷新或切页时会自动应用。

    

      
      
      
不勾选时可跨网站沿用，需额外授权。关闭标签页、重启浏览器或重载扩展会清除登记；“恢复原样”暂停沿用，手动应用后恢复。

      

    

    

  

  

    
页面标签

    
    
选中文字后点击“标记”。首次开启需授权网站访问，关闭不删除标签。未识别正文时，可在扩展面板填写选择器并重新识别。

    

  

  

    
正文处理上限

    
    
    
默认 60,000，范围 1–200,000。含正文容器及内部元素，保存后重新应用。
