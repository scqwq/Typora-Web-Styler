带来一个喜欢的主题

01 · 导入

导入本地文件，或粘贴喜欢的主题链接。下载后保存在这台设备上。

本地 CSS 与目录

最多 2 MB。导入后，会自动转换为正文可用的样式。

还有配套的字体或图片？

字体支持 WOFF / WOFF2 / TTF / OTF，图片支持 PNG / JPEG / WebP / GIF。最多 64 个资源，单个 16 MB、合计 24 MB。目录保留相对路径，并合并主 CSS 通过 @import 引用的包内 CSS；远程资源暂不加载。

导入本地 ZIP

ZIP 最多 48 MB，解压后最多 96 MB。无需手动解压。

从链接导入

可在 theme.typora.io 获取主题，将对应的主题页面或 GitHub 仓库主页链接粘贴到下方，插件会自动识别下载入口，选择主题后导入。不建议优先使用链接导入：部分下载包包含多个主题或配色版本，推荐自行下载、查看效果后使用本地导入。

仅支持 HTTPS。点击获取时按需申请下载来源访问权限；不会运行仓库脚本或自动更新主题。

亮色、暗色等分别导入。仅合并所选入口引用的包内 CSS；默认只显示主主题候选；字体依赖、在线入口和空文件不可单独导入。

保留网页的熟悉感
默认保留网站宽度、布局和代码配色，保护公式、图表与交互控件。背景图片默认关闭，可在上方开启；页面 CSP 可能影响资源加载。编辑器界面、动画与远程 @import 暂不支持，处理详情可在日志中查看。

主题沿用设置
04 · 自动应用

    
这里只设置偏好。在网页小窗口中成功应用一次主题后，才会记住那个标签页及所选主题。

    

      
      
已登记的标签页刷新、切换章节时自动识别正文。其他标签页不受影响；分别手动应用后可各自登记。

      
      
勾选后只跟随最初登记的网站；不勾选则可跟随该标签页跨网站导航，需要额外的网站访问授权。

      
关闭标签页、重启浏览器或重新加载扩展后，临时登记会清除。“恢复原样”会暂停该标签页自动应用，再次手动应用后恢复。识别不明确的页面会跳过。

      

    

    

  

  

    
页面标签设置

    
    
开启后自动在可识别正文的网页启用，选取词或短句后点击“标记”。首次开启需授权网站访问；关闭工具保留已保存的标签。自动识别失败时，可在扩展小窗口填写正文选择器并点击“识别正文”。

    

  

  

    
最大正文节点数

      
      
      
默认 60,000，范围 1–200,000。统计正文容器及其内部元素；保存后再次应用主题生效。
