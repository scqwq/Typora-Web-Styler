如何查找正文容器
  1. 在正文文字上右键，选择“检查”，打开开发者工具。
  2. 在“元素”面板向上选中父元素，直到网页高亮覆盖完整正文，同时避开导航、侧栏和输入框。
  3. 右键该元素，选择“复制 → 复制选择器（Copy selector）”。
  4. 把选择器粘贴到上方“正文在哪里？”输入框，再点击“识别正文”。确认范围后应用主题。

选择器应只匹配一个容器。若匹配多个，选择更具体的父元素；若匹配 0 个，等待正文加载后重新复制。不要选择 body 或 html。带自动生成类名或位置编号的选择器，刷新后可能失效。
